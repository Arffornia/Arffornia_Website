# Security policy

## Supported versions

Only the latest `main` (the version deployed in production) is supported.

## Reporting a vulnerability

Please report vulnerabilities privately with GitHub's **Report a vulnerability** button on this repository
(Security tab -> Advisories -> Report a vulnerability). Do not open a public issue.

Include what is affected, how to reproduce it, and the impact you expect. You will get an answer as soon as
the maintainer can look at it.
